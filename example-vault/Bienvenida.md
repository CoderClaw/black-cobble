# Bienvenida

Esta carpeta es una bóveda. Cada nota es un archivo **Markdown** que puedes abrir también con un editor de texto.

Escribe en una línea para ver su sintaxis. Al pasar a otra línea, aparece el formato.

## Prueba el editor

- Escribe **negrita**, *cursiva* o ~~tachado~~.
- Abre [[Proyectos/MVP|la nota del proyecto]].
- Abre [[Proyectos/Hoja de ruta.html|una nota HTML]].
- Crea un enlace nuevo: [[Mi primera nota]].

- [ ] Crear una nota
- [ ] Crear una subcarpeta
- [ ] Probar el tema claro

> Tus notas se guardan automáticamente en esta carpeta.

```js
const nota = 'Un archivo .md';
```

---

Usa Ctrl+N para crear una nota y Ctrl+S para guardar de inmediato.
